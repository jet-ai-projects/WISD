The teaser and overview PDFs are copied from the paper sources. The results
PDF contains the table cropped from the published paper; all 161 numeric
entries match the local LaTeX source. PNGs are rendered on a white background
at 2× resolution for the teaser and overview and 4× for the results table.
Each README image links to its vector PDF for zooming.
